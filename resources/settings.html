ABOUT SONDE

Minimal, Engineer-Grade Web Browser

Sonde is a lightweight, keyboard-driven browser engineered with a strict minimalist dark aesthetic, 0px border-radius, monospace typography, and full i18n support.

Version: 2.0.0-alpha.1
Engine: Rust // WebKitGTK & Wry
Architecture: x86_64 Desktop

МУЛЬТИАККАУНТНЫЕ КОНТЕЙНЕРЫ

Полная изоляция cookie, сессий и хранилища между контекстами в одном окне.

Контейнеры позволяют разделять профили работы, личных дел, банков и покупок. Каждый контейнер использует независимый контекст WebKitGTK (cookie, LocalStorage, IndexedDB), предотвращая отслеживание между сайтами и позволяя находиться под разными аккаунтами одновременно.

Изоляция Cookie и сессий Полная изоляция сессионных и постоянных куки между контейнерами.
Изоляция LocalStorage & IndexedDB Запретить веб-сайтам доступ к локальным хранилищам других контейнеров.
Очистка данных при закрытии вкладки Автоматически очищать временные данные контейнера при закрытии последней вкладки этого контейнера.
Контейнер по умолчанию для новых вкладок Выберите контейнер, который будет автоматически назначаться при создании новой вкладки.

КОНТЕЙНЕР ID ЦВЕТ ДЕЙСТВИЯ

КАК ИСПОЛЬЗОВАТЬ КОНТЕЙНЕРЫ:
  • Новая вкладка в контейнере: Нажмите стрелку ▾ рядом с кнопкой + НОВАЯ ВКЛАДКА в левой панели, либо кликните по ней правой кнопкой мыши.
  • Переоткрыть существующую вкладку: Кликните правой кнопкой мыши по любой вкладке в списке и выберите Переоткрыть в контейнере....
  • Индикация в интерфейсе: Вкладки контейнеров имеют цветную полосу слева и текстовый маркер с названием контейнера.
