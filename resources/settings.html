ABOUT ZEPHYRIUM

Minimal, Engineer-Grade Web Browser

Zephyrium is a lightweight, keyboard-driven browser engineered with a strict Anthropic Minimal Dark aesthetic, 0px border-radius, monospace typography, and full i18n support.

Version: 1.0.0 (Release)
Engine: Chromium // Qt6WebEngine
Architecture: x86_64 Linux
