# Zephyrium

Легковесный, модульный веб-браузер на базе PyQt6-WebEngine для Arch Linux, ориентированный на инженеров и опытных пользователей.

Zephyrium предоставляет три различных парадигмы интерфейса, изолированные контейнеры профилей, защищенное хранилище паролей и cookie с авторизацией через sudo, встроенную блокировку рекламы и трекеров на уровне сетевых запросов, динамические цветовые темы и интеграцию с Gemini API без лишней телеметрии и фоновых служб.

---

## Архитектура и режимы интерфейса

Zephyrium исключает компромиссы перегруженных интерфейсов, предлагая две отточенные парадигмы работы:

1. **Minimal Mode (По умолчанию)**
   - Строгая эстетика: радиус скруглений 0px, границы 1px, моноширинные шрифты.
   - **Смена ориентации вкладок (`Ctrl+Alt+T`)**:
     - *Вертикальная боковая панель*: фиксированная ширина вкладок с цветовой кодировкой контейнеров слева, сворачивание в компактную полосу 50px (`Ctrl+[`).
     - *Горизонтальные верхние вкладки*: традиционное размещение вкладок сверху над страницей с аккуратными квадратными кнопками закрытия.
   - Минималистичная панель навигации с лаконичными индикаторами статуса.

2. **Vim Mode**
   - Полноэкранный режим чтения без отвлекающих элементов. Панели навигации и списки вкладок скрыты.
   - Управление и ввод адресов через командную строку статуса (`:`).
   - Выделенная кнопка `[ВЫЙТИ ИЗ VIM]` в углу экрана и возврат по клавише `Escape`.
   - Быстрые одноклавишные команды перехода (`o`, `t`, `d`, `J`, `K`, `r`, `yy`, `H`, `L`).

Переключение между режимами выполняется в любой момент по `Ctrl+M`, через меню статусной строки или с помощью флага командной строки `--mode {minimal,vim}`.

## Цветовые темы и акценты

В Zephyrium встроена система мгновенного применения стилей без перезапуска приложения:

- **Темы оформления:** Claude Code Minimal Dark (темная) и Clean Paper Light (светлая).
- **Цветовые акценты:**
  - Zephyrium Amber (`#fe8019`)
  - Изумрудный зеленый (`#10b981`)
  - Небесно-голубой (`#38bdf8`)
  - Лавандовый фиолетовый (`#a855f7`)
  - Северная роза (`#f43f5e`)
  - Монохромный сланец (`#94a3b8`)

Выбор темы и акцентного цвета доступен в настройках (`Ctrl+,`) и на стартовой странице первого запуска (`zephyrium://welcome`).

## Ключевой функционал

- **Изолированные контейнеры**: Раздельные профили `QWebEngineProfile` (Default, Work, Personal, Dev, Incognito) с независимыми cookie, кешем и локальным хранилищем.
- **Защищенное хранилище (Vault)**: Вкладка настроек `04 // Пароли и Cookie`, доступ к которой защищен системной авторизацией `sudo`. Просмотр, копирование и экспорт учетных данных в CSV, JSON и формата Netscape TXT.
- **Универсальный импорт данных**: Автоматическое обнаружение системных и Flatpak-установок Google Chrome, Chromium, Microsoft Edge, Brave и Mozilla Firefox. Импорт закладок, истории, cookie и сохраненных паролей, а также поддержка импорта паролей из CSV.
- **Усыпление неактивных вкладок**: Фоновые вкладки автоматически переходят в спящий режим через 20 минут неактивности, освобождая оперативную память с сохранением состояния страницы. Ручной перевод в спящий режим доступен через контекстное меню.
- **Блокировщик рекламы и приватность**: Блокировка на уровне перехвата сетевых URL-запросов со списком исключений (`~/.config/zephyrium/adblock_whitelist.json`). Автоматическая очистка трекинговых меток (`utm_*`, `fbclid`, `gclid`). Переключение Tor/SOCKS5 прокси (`127.0.0.1:9050`).
- **Архитектура единого инстанса (IPC)**: Локальный сокет домена Unix (`zephyrium_ipc_sock`) перенаправляет последующие вызовы из консоли (`zephyrium <url>`) в уже работающий процесс, не создавая дублирующих процессов браузера.
- **Ассистент на базе Gemini API**: Боковая панель анализа страницы (`@page <запрос>`) с динамической загрузкой списка моделей через Google Generative Language API и автоматической рекомендацией быстрых моделей (`gemini-3.8-flash-lite`, `gemini-2.5-flash`).
- **Интернационализация (i18n)**: Встроенный перевод на 10 языков: английский, русский, китайский (упрощенный), испанский, немецкий, французский, японский, португальский, итальянский и турецкий.
- **Интеграция с Wayland и окружением рабочего стола**: Процесс именуется как `zephyrium` через вызов `prctl(PR_SET_NAME)`. Параметр `StartupWMClass=zephyrium` обеспечивает корректную группировку окон в Waybar, Hyprland, Sway, GNOME и KDE. При закрытии последней оставшейся вкладки окно браузера закрывается.

## Горячие клавиши

### Глобальные сочетания

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Ctrl + M` | Циклическое переключение режимов (Minimal <-> Vim) |
| `Ctrl + Alt + T` | Смена ориентации вкладок (вертикальные / горизонтальные) |
| `Ctrl + [` | Свернуть / развернуть боковую панель вкладок (50px / 240px) |
| `Ctrl + ,` | Открыть окно настроек и хранилище |
| `Ctrl + K` | Открыть командную палитру и список клавиш (Keybinds) |
| `Ctrl + L` | Переместить фокус в адресную строку |
| `Ctrl + T` | Создать новую вкладку |
| `Ctrl + W` | Закрыть текущую вкладку (закрывает браузер при закрытии последней) |
| `Ctrl + \` | Включить / выключить разделение экрана (Split View) |
| `Ctrl + B` | Открыть боковую панель заметок и ассистента |
| `Ctrl + Shift + D` | Показать панель загрузок |
| `Alt + Shift + W` | Новая вкладка в контейнере Work |
| `Alt + Shift + D` | Новая вкладка в контейнере Dev |
| `Alt + Shift + I` | Новая вкладка в режиме Incognito |
| `Ctrl + R` / `F5` | Перезагрузить страницу |
| `Ctrl + Shift + R` | Полная перезагрузка без использования кеша |
| `Ctrl + +` / `Ctrl + -` | Увеличение / уменьшение масштаба |
| `Ctrl + 0` | Сброс масштаба на 100% |
| `F11` | Полноэкранный режим |

### Команды Vim Mode

| Клавиша / Команда | Действие |
| :--- | :--- |
| `:` | Открыть строку ввода команд |
| `o` | Ввод нового адреса или поискового запроса |
| `t` | Открыть новый адрес в новой вкладке |
| `d` | Закрыть текущую вкладку |
| `J` / `K` | Следующая / предыдущая вкладка |
| `r` / `R` | Перезагрузка страницы / перезагрузка без кеша |
| `yy` | Скопировать адрес текущей страницы в буфер обмена |
| `H` / `L` | Навигация назад / вперед по истории |
| `Escape` | Закрыть строку ввода или выйти из режима Vim |

## Установка и запуск в Arch Linux

### Системные требования

- Arch Linux или дистрибутивы на его базе (EndeavourOS, Manjaro и др.)
- Python 3.10+
- Библиотеки Qt6 и Qt6 WebEngine

### Быстрый запуск из терминала

Исполняемые файлы `zephyrium` и `zephyrium-browser` (а также символическая ссылка `zinc`) размещены в `~/.local/bin/`:

```bash
# Запуск в стандартном минималистичном режиме:
zephyrium

# Открытие страницы:
zephyrium https://wiki.archlinux.org

# Запуск в определенном режиме:
zephyrium --mode minimal
zephyrium --mode vim

# Запуск в изолированном контейнере:
zephyrium --container dev https://github.com
```

### Запуск из директории исходного кода

```bash
cd /home/qualbyy/.gemini/antigravity/scratch/zinc-browser
./run.sh
```

## Файлы конфигурации

Конфигурационные данные хранятся в домашнем каталоге пользователя в соответствии со стандартом XDG Base Directory:

- Настройки браузера: `~/.config/zephyrium/settings.json`
- Белый список блокировщика рекламы: `~/.config/zephyrium/adblock_whitelist.json`
- Хранилище паролей: `~/.config/zephyrium/passwords.json`
- Файл cookie: `~/.config/zephyrium/cookies.json`
- Закладки: `~/.config/zephyrium/bookmarks.json`
- История посещений: `~/.config/zephyrium/history.json`
- Профили контейнеров: `~/.config/zephyrium/profiles/`
- Пользовательские стили CSS: `~/.config/zephyrium/custom.qss`
